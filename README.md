## 🇧🇷 Português

### Sobre o repositório

Este repositório reúne códigos, exercícios e atividades desenvolvidos durante a disciplina **Linguagem de Programação para Web I**, da Faculdade de Tecnologia e Inovação Senac-DF, turma/período 2.25.

O objetivo é documentar a evolução do aprendizado em desenvolvimento Web, mantendo exemplos organizados para consulta e revisão.

### Organização

```text
lpwi-2.25/
├── aula01/
├── aula02-variaveis/
└── README.md
```

O conteúdo está organizado por aula ou assunto. Novas atividades podem ser adicionadas conforme o avanço da disciplina.

### Como utilizar

1. Clone o repositório.
2. Abra a pasta da aula desejada.
3. Consulte os arquivos e execute os exemplos conforme as orientações da atividade.

```bash
git clone https://github.com/mardenmartins/lpwi-2.25.git
cd lpwi-2.25
```
